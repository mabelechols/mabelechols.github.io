Thermal Properties of AlGaN using MD

During the summer of 2024, I worked as an undergraduate researcher in the McGaughey Lab at Carnegie Mellon. My project focused on studing the thermal properties of Aluminum/Gallium Nitride alloys using Molecular Dynamics (MD) simulations. I used LAMMPS, an industry standard MD code to perfom my simulations, modifying it as needed for my project. My fork of LAMMPS is here, and contains custom code which allows for a "Virtual Crystal Approximation" to be used. Learn more below!
